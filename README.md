# Snowgame releases

Builds of **Snowgame**, a cozy ski resort tycoon. Install with the launcher, which keeps the game up to date on its own.

## macOS

```sh
brew install --cask kaileh57/snowgame/snowgame
```

## Windows

Download `SnowgameSetup.exe` from the [latest release](https://github.com/kaileh57/snowgame-releases/releases/latest) and run it. It installs into `%APPDATA%\Snowgame` and appears in **Add or remove programs**.

The builds are unsigned for now. On first run, Windows SmartScreen shows "Windows protected your PC": click **More info**, then **Run anyway**.
